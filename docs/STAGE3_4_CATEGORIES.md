# Stage 3.4 — категории расходов

- Пользователи общей активной цели могут создавать собственные категории.
- Собственная категория поддерживает название, значок, цвет и признак «необязательный по умолчанию».
- Собственная категория архивируется мягко: старые расходы сохраняют ссылку и название, а активные правила категоризации для неё отключаются.
- Архивную собственную категорию можно восстановить.
- Системные категории нельзя переименовать или архивировать.
- Цвет, значок и признак необязательности системной категории задаются через `expense_category_overrides` отдельно для каждой цели; глобальная системная строка не меняется.
- Дашборд использует фактические цвета и значки категорий.
- Изменения категорий участвуют в аудите и Realtime.
