## Мультивалютность

Цель имеет одну основную валюту отображения. Первая версия должна поддерживать:

- KZT — казахстанский тенге;
- EUR — евро;
- USD — доллар США;
- RUB — российский рубль.

Отдельное накопление может быть в валюте, отличной от основной валюты цели. В общей сумме и прогрессе оно отображается после конвертации.

Обязательные правила будущей реализации:

- исходная сумма и исходная валюта никогда не теряются;
- финансовые значения не вычисляются через binary floating point;
- у каждой конвертации видны источник курса, дата/время курса и рассчитанный эквивалент;
- устаревший курс явно помечается;
- приложение не подменяет историческую исходную сумму новым значением;
- изменение курса меняет только отображаемый эквивалент и прогресс в основной валюте, а не исходную операцию;
- перед реализацией выбирается надёжный источник курсов и политика обновления/кэширования.

## Данные при переходе из beta

Переход на обычный публичный релиз не требует новой базы. Production Supabase сохраняется, а схема меняется только миграциями. Название Vercel-проекта, URL и UI можно менять без удаления пользовательских данных.
