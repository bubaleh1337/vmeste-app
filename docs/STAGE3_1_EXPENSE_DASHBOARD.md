# Этап 3.1 — русская локализация импорта и дашборд расходов

- Нативный англоязычный file input заменён на собственную русскую кнопку выбора файла.
- Пользовательский текст больше не упоминает Supabase или preview.
- Даты в проверке импорта отображаются в формате ДД.ММ.ГГГГ.
- На экране цели добавлен дашборд расходов: всего, обязательные, потенциальные накопления, категории текущего месяца и сравнение с предыдущим месяцем.
- Диаграмма имеет текстовый эквивалент по категориям и не передаёт данные только цветом.
- Операции со статусом needs_review не входят в расчёты и отображаются отдельным предупреждением.
